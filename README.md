# Webpage of the Yes!kino art project

Intended to be hosted at `https://yeskino.janafrancova.cz`.

Simple html and css webpage made manually without redaction software, focusing on understanding the principles of html and css alone. Generative AI was mostly used for consulting and getting tips on what to use than generating parts of code alone.

Site uses google font Paytone One and Add to Calendar button feature from `https://addtocalendar.com`.
