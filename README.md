# Webpage of the Yes!kino art project

Webpage for the international student video contest in Brno, part of the BrnoArtWeek festival in recent years.

Intended to be hosted at `https://yeskino.janafrancova.cz`.

Simple html and css webpage made manually without redaction software. Generative AI was only used for consulting and getting tips on what to use rather than generating whole parts of source code.

Site uses google font Paytone One and Add to Calendar button feature from `https://addtocalendar.com`.
